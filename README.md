# Видеозвонок 1 на 1 (WebRTC)

Статический сайт без сборки: `index.html`, `style.css`, `app.js`.
Signaling: `wss://inai-col3.fishrungames.com/signaling/`.

## Как это работает

1. Страница запрашивает камеру/микрофон и подключается к WebSocket.
2. Кто нажимает «Позвонить» — создаёт `offer` и отправляет его через сервер.
3. Второй участник автоматически получает `offer`, отвечает `answer`.
4. Стороны обмениваются ICE-кандидатами (`candidate`).
5. Сообщение `{ type: 'peer-left' }` от сервера закрывает соединение и очищает видео собеседника.

Формат сообщений: `{type: "offer", offer}`, `{type: "answer", answer}`, `{type: "candidate", candidate}`.

## Локальный запуск

Камера работает только на `https://` или `http://localhost`, поэтому открывать файл через `file://` нельзя:

```
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в двух окнах, в одном нажмите «Позвонить».

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите 4 файла в корень.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по `https://<username>.github.io/<repo>/`.
4. Проверьте звонок между двумя вкладками/устройствами.

## Заметки

- Если подключится третий клиент, сервер отключит первого — появится кнопка «Переподключиться».
- Используются только STUN-серверы; за строгим NAT может понадобиться TURN.
